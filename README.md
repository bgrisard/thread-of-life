# thread of life

An endless, traceable thread through Scripture. Each card is one verse; the
steps scroll inside it — the verse, how it points to Jesus, every
cross-reference in turn, the historical setting, a commentary.

## Put it online (GitHub Pages, no build required)

1. Push this repo to GitHub.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / **`/docs`**.
3. It goes live at `https://<user>.github.io/<repo>/`.

`docs/` is a prebuilt static site — one HTML file plus the data. Nothing to
install, nothing to compile. `.nojekyll` is already there so Pages serves the
data folder untouched.

After changing `src/App.jsx`, regenerate it:

```bash
python3 scripts/build-site.py
```

The script precompiles the JSX with esbuild rather than letting Babel do it in
the browser. That is deliberate: Babel's in-browser React preset defaults to the
automatic JSX runtime, which emits `import { jsx } from "react/jsx-runtime"` —
an import statement inside a classic `<script>`, which browsers reject. The
result is a page that loads and renders nothing. The build fails loudly if any
module-only syntax survives.

## Run it locally

```bash
npm install
npm run dev
```

Vite serves from `src/` and `public/`. For a Vite production build aimed at a
project Pages URL, set the base path: `VITE_BASE=/<repo>/ npm run build`.

## What ships in the files

| | |
| --- | --- |
| Text | Berean Standard Bible, 31,086 verses, all 66 books |
| Licence | Public domain (CC0), dedicated 30 April 2023 |
| Cross-references | 343,608 links from OpenBible.info (Treasury of Scripture Knowledge), CC BY 4.0 |
| Stored per verse | top 8 by vote count; the app walks the top 5 |
| Size | 7.4 MB, one file per book, loaded on demand |

Scripture and cross-references need no network and no key. Verify the data with
`npm run verify-data` — expects 66/66 books, 0 dangling links.

**Sixteen omitted verses.** The BSB prints Matt 17:21, 18:11, 23:14; Mark 7:16,
9:44, 9:46, 11:26, 15:28; Luke 17:36, 23:17; John 5:4; Acts 8:37, 15:34, 24:7,
28:29; Rom 16:24 as omitted, because the earliest manuscripts do not contain
them. Absent by editorial decision, not missing data. The app says so when you
land on one.

## What needs a network

| Step | Needs | Without it |
| --- | --- | --- |
| Finding Jesus | Anthropic API key | says so, card still works |
| Where and when | Anthropic API key | says so, card still works |
| Cross-reference notes | Anthropic API key | verse still shown, note omitted |
| Commentary | Free Use Bible API, no key | reports no note available |

Paste a key in the **Debug** tab. Calls are queued two at a time and retry with
backoff on rate limits.

### The key is exposed in the browser

The app calls Anthropic directly from the page, so the key is readable by anyone
using that browser. Fine for your own device. **Before sharing the URL**, move
the call behind a server route — a Cloudflare Pages Function or equivalent —
with the key in an encrypted environment variable.

## The governing rule

Scripture text is never generated by a language model, and none of it was
written from model recall. Every word comes from the BSB dataset. The model
writes commentary only, under three guardrails in `src/App.jsx` (`P_LINK`,
`P_HISTORY`, `P_CHRIST`), all inheriting `CORE`.

## Rebuilding the data

`python3 scripts/build-data.py` regenerates `public/data/` from source datasets.
It needs `bsb.json` (scrollmapper/bible_databases) and the OpenBible
cross-reference TSV alongside it.
